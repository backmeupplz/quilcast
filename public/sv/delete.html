Radera ditt Quilcast-konto

Quilcast, från Borodutch Labs Inc.

Kontot du använder i Quilcast är ett Farcaster-konto, som finns i det offentliga Farcaster-nätverket och på blockkedjan Optimism, inte hos oss. Du kan radera det inifrån appen, och den här sidan förklarar vad som då tas bort och vad som finns kvar.

I appen

Öppna Inställningar med kontot valt och tryck på Radera konto, under Logga ut. När du har bekräftat gör Quilcast följande och visar hur långt det har kommit:

  1. Vår server raderar allt den sparar för kontot: dess profilutseende, listor över tystade och blockerade, utkast, sparade översättningar av dess casts, samt de foton och videor som bara det här kontot har laddat upp till vår server.
  2. Dina casts, gillamarkeringar, recasts och följningar tas bort från Farcaster-nätverket, och din profil (bild, namn, bio, webbplats, plats, X-användarnamn och banner) töms. Appen kontrollerar nätverket efteråt och berättar om något ligger kvar.
  3. Därefter loggar Quilcast ut på samma sätt som Logga ut gör: nyckeln som lades till på Optimism för notiser från miniappar tas bort, kontots signeringsnyckel återkallas så att nätverket slutar acceptera den, notisinkorgen på vår server tas bort, och återställningsfrasen och nycklarna raderas från din enhet.

Om något steg misslyckas sker inget av det som kommer efter, och appen berättar vad som gick fel, så du kan helt enkelt köra det igen.

Vad som finns kvar

Ditt Farcaster-ID förblir registrerat på blockkedjan Optimism, eftersom ingen kan radera det, och dess användarnamn, verifierade plånboksadresser och GitHub-namn finns kvar med det (appen som verifierade en adress kan ta bort den). Den som har dess återställningsfras, eller plånboken som äger det, styr fortfarande det ID:t. Andra Farcaster-appar och indexerare kan ha kvar kopior av offentliga meddelanden som de redan har sett, och foton som laddats upp till Farcasters egen bildtjänst finns kvar där.

På vår server finns ett foto eller en video kvar när ett annat konto har laddat upp samma fil eller när ett tema använder den, och likaså alla som låg på vår server innan vi började registrera vem som laddade upp varje fil (med uppdateringen som införde fullständig kontoradering, i slutet av oktober 2026), eftersom vi inte med säkerhet kan avgöra vems de är. Appen berättar hur många av dina som behölls; skicka e-post till oss så tar vi bort dem. Teman som du delat via länk är inte heller kopplade till ditt konto, så skicka e-post till oss om du vill att något ska tas ner.

Bara den här enheten

Om du vill ta bort ett konto från en enhet utan att radera det, öppna Inställningar och logga ut. Då tas dess nycklar bort, liksom signeringsnyckeln som Quilcast lade till för den här enheten (nätverket får veta att det ska sluta acceptera den). När du avinstallerar appen tas allt annat den har sparat bort.

Via e-post

Om du inte kan använda appen, skicka e-post till support@borodutch.com med ditt Farcaster-användarnamn eller ID. Inom 30 dagar raderar vi allt som finns sparat på vår server för det kontot: ditt profilutseende, sparade teman, listor över tystade och blockerade, utkast, foton och videor som laddats upp till vår server samt notistokens för miniappar. Du kan också be om att bara en del av det raderas. Meddelanden på själva Farcaster kan bara tas bort med kontots nycklar, från Quilcast eller en annan Farcaster-app.
