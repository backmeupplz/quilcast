ลบบัญชี Quilcast ของคุณ

Quilcast โดย Borodutch Labs Inc.

บัญชีที่คุณใช้ใน Quilcast เป็นบัญชี Farcaster ซึ่งอยู่บนเครือข่าย Farcaster สาธารณะและบล็อกเชน Optimism ไม่ได้อยู่กับเรา คุณลบบัญชีได้จากภายในแอป และหน้านี้อธิบายว่าการลบนำอะไรออกและอะไรยังคงอยู่

ในแอป

เปิดการตั้งค่าโดยเลือกบัญชีนั้นไว้ แล้วแตะ ลบบัญชี ซึ่งอยู่ใต้ปุ่มออกจากระบบ เมื่อคุณยืนยันแล้ว Quilcast จะทำสิ่งต่อไปนี้ พร้อมแสดงความคืบหน้าไปเรื่อย ๆ:

  1. เซิร์ฟเวอร์ของเราลบทุกอย่างที่เก็บไว้สำหรับบัญชีนั้น ได้แก่ การตกแต่งโปรไฟล์ รายการปิดเสียงและรายการบล็อก ฉบับร่าง คำแปลที่บันทึกไว้ของแคสต์ของบัญชี และรูปภาพกับวิดีโอที่มีเฉพาะบัญชีนี้เป็นผู้อัปโหลดไปยังเซิร์ฟเวอร์ของเรา
  2. แคสต์ การถูกใจ รีแคสต์ และการติดตามของคุณจะถูกนำออกจากเครือข่าย Farcaster และโปรไฟล์ของคุณ (รูปภาพ ชื่อ ประวัติย่อ เว็บไซต์ ที่ตั้ง ชื่อผู้ใช้ X และแบนเนอร์) จะถูกล้างให้ว่าง จากนั้นแอปจะตรวจสอบเครือข่ายอีกครั้งและแจ้งให้คุณทราบถึงสิ่งที่ยังเหลืออยู่
  3. จากนั้น Quilcast จะออกจากระบบเหมือนกับที่ปุ่มออกจากระบบทำ คือ คีย์ที่เพิ่มบน Optimism สำหรับการแจ้งเตือนของมินิแอปจะถูกนำออก คีย์ลงนามจะถูกเพิกถอนเพื่อให้เครือข่ายเลิกรับคีย์นั้น กล่องข้อความแจ้งเตือนบนเซิร์ฟเวอร์ของเราจะถูกลบ และวลีกู้คืนกับคีย์จะถูกลบจากอุปกรณ์ของคุณ

หากขั้นตอนใดล้มเหลว ขั้นตอนหลังจากนั้นจะไม่เกิดขึ้น และแอปจะแจ้งว่าเกิดอะไรขึ้น คุณจึงเริ่มทำใหม่ได้เลย

สิ่งที่ยังคงอยู่

Farcaster ID ของคุณยังคงลงทะเบียนอยู่บนบล็อกเชน Optimism เพราะไม่มีใครลบได้ และชื่อผู้ใช้ ที่อยู่กระเป๋าเงินที่ยืนยันแล้ว และชื่อ GitHub ก็ยังอยู่กับ ID นั้น (แอปที่ยืนยันที่อยู่สามารถนำที่อยู่นั้นออกได้) ผู้ที่ถือวลีกู้คืนของ ID นั้น หรือกระเป๋าเงินที่เป็นเจ้าของ ID นั้น ยังคงควบคุม ID นั้นอยู่ แอป Farcaster อื่นและตัวทำดัชนีอาจเก็บสำเนาของข้อความสาธารณะที่เห็นไปแล้ว และรูปภาพที่อัปโหลดไปยังบริการรูปภาพของ Farcaster เองก็ยังอยู่ที่นั่น

บนเซิร์ฟเวอร์ของเรา รูปภาพหรือวิดีโอจะยังอยู่เมื่อบัญชีอื่นอัปโหลดไฟล์เดียวกัน หรือเมื่อมีธีมใช้ไฟล์นั้น และรวมถึงไฟล์ที่อยู่บนเซิร์ฟเวอร์ของเราก่อนที่เราจะเริ่มบันทึกว่าใครอัปโหลดแต่ละไฟล์ (ด้วยการอัปเดตที่เพิ่มการลบบัญชีแบบสมบูรณ์ เมื่อปลายเดือนตุลาคม 2026) เพราะเราไม่สามารถระบุได้แน่ชัดว่าไฟล์เหล่านั้นเป็นของใคร แอปจะแจ้งว่าไฟล์ของคุณถูกเก็บไว้กี่รายการ ส่งอีเมลถึงเราแล้วเราจะลบให้ ธีมที่คุณแชร์ด้วยลิงก์ก็ไม่ได้ผูกกับบัญชีของคุณเช่นกัน หากต้องการให้ถอนธีมใด ให้ส่งอีเมลถึงเรา

เฉพาะอุปกรณ์นี้

หากต้องการนำบัญชีออกจากอุปกรณ์เครื่องเดียวโดยไม่ลบบัญชี ให้เปิดการตั้งค่าแล้วออกจากระบบ ซึ่งจะลบคีย์ของบัญชีและคีย์ลงนามที่ Quilcast เพิ่มไว้สำหรับอุปกรณ์นี้ (เครือข่ายจะได้รับแจ้งให้เลิกรับคีย์นั้น) การถอนการติดตั้งแอปจะลบทุกอย่างที่เหลือที่แอปเก็บไว้

ทางอีเมล

หากคุณใช้แอปไม่ได้ ให้ส่งอีเมลถึง support@borodutch.com พร้อมชื่อผู้ใช้หรือ Farcaster ID ของคุณ ภายใน 30 วัน เราจะลบทุกอย่างที่เก็บไว้บนเซิร์ฟเวอร์ของเราสำหรับบัญชีนั้น ได้แก่ การตกแต่งโปรไฟล์ ธีมที่บันทึกไว้ รายการปิดเสียงและรายการบล็อก ฉบับร่าง รูปภาพและวิดีโอที่อัปโหลดไปยังเซิร์ฟเวอร์ของเรา และโทเค็นการแจ้งเตือนของมินิแอป คุณยังขอให้ลบเพียงบางส่วนก็ได้ ข้อความบน Farcaster เองลบได้ด้วยคีย์ของบัญชีเท่านั้น จาก Quilcast หรือแอป Farcaster อื่น
