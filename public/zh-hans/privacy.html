隐私政策

Quilcast，由 Borodutch Labs Inc. 出品。最后更新于 2026年11月6日。

Quilcast 没有自己的账号体系，没有广告，没有数据分析，也不做追踪。本页列出你在网页或 Quilcast 应用中使用 Quilcast 时，离开你设备的全部数据。

在你的设备上

你的助记词、钱包密钥和签名密钥都在你的设备上创建和保存，并由设备持有的密钥加密。它们绝不会发送给我们。设置、草稿和你使用的账号也保存在你的设备上。

Farcaster 网络

信息流、个人主页和帖子从公共的 Farcaster（Hypersnap）节点读取，你发布、点赞、转发或关注的内容会在你的设备上签名后发送给该节点。Farcaster 上的一切都是公开的。

我们的服务器（quilcast.com）

  • 你附在帖子上的照片和视频通过它上传，并可能存放在那里以便公开访问，同时记录是哪个 Farcaster ID 上传的，这样它们可以随账号一起删除。
  • 你保存的主页外观和主题、你置顶到主页的帖子、你的静音和屏蔽列表以及你的草稿都存放在那里，并与你的 Farcaster ID 关联。静音和屏蔽列表只能用你的密钥读取，草稿在你的设备上加密封存，只有你能读取。
  • 链接预览、翻译（帖子的文字会通过 OpenRouter 发送给翻译模型）、小程序列表和 GIF 搜索都通过它获取。
  • 你从 ⋯ 菜单发送的举报会存放在那里，供我们的审核人员查看：你举报了什么、原因、你的备注，以及你已登录时的 Farcaster ID。
  • 私信和语音空间会转发到 farcaster.xyz，不会被存储或记录日志。
  • 如果你开启小程序通知，会存储一个随机的收件箱 ID 和你浏览器的推送订阅，用于送达通知。
  • 如果你为账号动态开启推送通知，我们会保存你的 Farcaster ID、浏览器的推送订阅以及你为它选择的设置（哪些类型、语言、是否隐藏垃圾内容），并在几分钟内记录已经发送过哪些通知，以便服务器每分钟查看一次你的通知并推送新的内容。退出登录或删除账号会清除这些信息。
  • 它会统计每天有多少个账号使用过它，以及有多少次首次登录来自我们的各个推广链接（链接的名称会保存在你的浏览器里，直到你登录）。我们只保留这些汇总数字，不含任何关于具体是谁的信息，并且它们公开显示在 quilcast.com/api/stats。
  • 你的 IP 地址仅在内存中用于限制请求频率。本站通过 Cloudflare 提供服务，我们的托管服务出于安全考虑会保留短期的请求日志（地址、时间、页面）。

其他服务

根据你使用的功能而定：farcaster.xyz（私信、语音空间、上传到 Farcaster 的图片 CDN）、LiveKit（语音空间的音频）、Farcaster 的图片 CDN、Tenor（GIF）、YouTube（主页歌曲）、公共区块链 RPC 和 Blockscout（钱包余额）、LI.FI（兑换报价），以及你打开的小程序。它们各有自己的隐私政策。

儿童

Quilcast 不适合 13 岁以下的儿童使用。

联系方式

如需删除你的账号和我们保存的数据，请在 Quilcast 中使用“设置 → 删除账号”；删除你的账号说明了它会删除什么，以及如何改用电子邮件提出请求。如有疑问：support@borodutch.com · 使用条款
