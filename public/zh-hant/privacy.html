隱私權政策

Quilcast，由 Borodutch Labs Inc. 提供。最後更新：2026年10月31日。

Quilcast 沒有自己的帳號系統，沒有廣告，沒有分析工具，也不做任何追蹤。本頁列出你在網頁或 Quilcast 應用程式中使用 Quilcast 時，離開你裝置的所有資料。

在你的裝置上

你的復原詞組、錢包金鑰和簽署金鑰都是在你的裝置上建立並保存，並以裝置持有的金鑰加密。這些資料絕不會傳送給我們。設定、草稿和你使用的帳號也同樣儲存在你的裝置上。

Farcaster 網路

動態、個人檔案和貼文是從公開的 Farcaster（Hypersnap）節點讀取的；你發佈、按讚、轉發或追蹤的內容，會在你的裝置上簽署後傳送到該節點。Farcaster 上的一切內容都是公開的。

我們的伺服器（quilcast.com）

  • 你附加在貼文中的相片和影片會經由伺服器上傳，並可能存放在那裡以供公開讀取，同時會記錄是哪個 Farcaster ID 上傳的，以便在刪除帳號時一併刪除。
  • 你儲存的個人檔案外觀和主題、你釘選在個人檔案的貼文、你的靜音與封鎖名單，以及你的草稿，都存放在那裡，並與你的 Farcaster ID 綁定。靜音與封鎖名單只有用你的金鑰才能讀取，草稿則在你的裝置上加密封存，只有你能讀取。
  • 連結預覽、翻譯（貼文文字會透過 OpenRouter 送到翻譯模型）、小程式清單和 GIF 搜尋，都是經由伺服器取得。
  • 你從 ⋯ 選單送出的檢舉會存放在那裡，供我們的審核人員查看：包括你檢舉的內容、原因、你的備註，以及（若你當時已登入）你的 Farcaster ID。
  • 私訊和語音空間會轉送到 farcaster.xyz，不會被儲存或記錄。
  • 如果你開啟小程式通知，我們會儲存一組隨機的收件匣 ID 和你瀏覽器的推播訂閱資料，用來傳送通知。
  • 你的 IP 位址只會在記憶體中用於流量限制。本網站透過 Cloudflare 提供服務，我們的主機服務會為了安全而保留短期的請求記錄（位址、時間、頁面）。

其他服務

視你使用的功能而定：farcaster.xyz（私訊、語音空間、上傳到 Farcaster 的圖片 CDN）、LiveKit（語音空間的音訊）、Farcaster 的圖片 CDN、Tenor（GIF）、YouTube（個人檔案歌曲）、公開的區塊鏈 RPC 和 Blockscout（錢包餘額）、LI.FI（兌換報價），以及你開啟的小程式。這些服務各有自己的隱私權政策。

兒童

Quilcast 不是為 13 歲以下的兒童設計的。

聯絡我們

若要刪除你的帳號和我們保存的資料，請在 Quilcast 中使用「設定」→「刪除帳號」；刪除你的帳號會說明刪除的範圍，以及如何改用電子郵件提出要求。如有疑問：support@borodutch.com · 使用條款
